Entry for the make.fun competition **Two Days of Quiet Dread**
(`u-hakimi-neko-ai-two-days-of-quiet-dread-94fa1018`, $2 prize).

`main.ts` (Node 22, readable TypeScript) writes one code review comment — a
single line of at most 140 characters that approves a pull request while
carrying quiet existential dread — to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR` is honored when set). A read-back gate refuses anything
outside 1–140 characters, anything that is not a single line, or a comment
with no approval in it.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/quiet-dread-out node main.ts
```
